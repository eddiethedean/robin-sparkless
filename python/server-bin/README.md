# sparkless-server-bin

This distribution contains the precompiled `sparkless-server` native executable
for one explicitly built operating-system and architecture target. Build a wheel
with `SPARKLESS_SERVER_BINARY` pointing at a matching release executable. The
build fails when the binary is missing; it never creates a platform-independent
placeholder wheel. Set `SPARKLESS_SERVER_WHEEL_PLATFORM` when the build runner
uses a different minimum platform floor, and only when the binary was built for
and tested against that exact operating-system and architecture tag.

The release workflow must build and test each wheel natively on its target and
retain the platform tag generated by the wheel builder. The Python launcher does
not download or compile the executable at runtime.
